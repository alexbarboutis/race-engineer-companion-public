# Public edition scope

This project includes the timing application, GUI, service-duration arithmetic and an independent constant-pace baseline. Its bundled data is generated fictionally by `race_companion/demo.py`.

No HH Timing application binaries, SDK assemblies or bridge implementation are distributed here. HH Timing is a third-party product; this project is not an official HH Development application.

Advanced traffic-interaction modelling, calibration data and reference simulation sources are not part of this edition.
